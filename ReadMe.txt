Simply drag & drop an ISO/WBFS/RVZ file onto the PatchIt!.bat batch file to begin
the patching process. The batch will likely work properly only on Windows.

Linux and Mac users may be able to run the patcher batch via Wine, though no idea
whether the "patcher" batch and the that tools it relies on will function correctly,
sorry. Just be sure to pass the input image after the batch file via CLI, since
drag-and-drop probably won't work in this scenario.
